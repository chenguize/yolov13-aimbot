# 1.2 PROController (Bio-Trajectory Planner / 生物力学弹道规划器)

**定位**：高级拟人化与实战强化首选控制器

**核心理念**：  
彻底放弃传统的被动误差反馈（PID）逻辑，转向主动的 **“感官-运动规划 (Sensory-Motor Planning)”** 模式。  
系统不再机械地“追逐”当前目标坐标，而是利用你本人录制的生物动力学数据，规划出一段具备强烈“人类指纹”特征的理想弹道轨迹。

## 主要特性与演进流程

### 1. Fitts 物理对齐 (Physical Legitimacy)

- **原理**：接入通过 PsyToolkit Fitts demo 录制的个人原始数据，建立经典 Fitts 定律模型  
  $MT = a + b \cdot \log_2(2D/W + 1)$
- **逻辑**：系统根据实时误差距离 $D$ 自动插值计算出该距离下人类生理上合理的移动时间 $MT$
- **强化体现**：将反应时参数 $a$ 锁定在人类巅峰极限（约 120ms 左右），在完全符合物理与生物学边界的前提下，实现超越普通玩家的反应速度

### 2. Minimum Jerk 弹道合成 (Bio-Smoothness)

- **算法**：完全抛弃机械感强烈的线性加速或 PID 增益调度  
- **核心**：采用生物力学领域公认的 **Minimum Jerk Curve**（最小加加速度轨迹）
- **速度分布**：生成经典的“钟形速度曲线”（Bell-shaped velocity profile），完美模拟人类肌肉协同收缩的自然加速-峰值-减速过程
- **效果**：彻底消除传统 PID 常见的起始阶跃式抖动和不自然突变，使轨迹平滑度达到人类运动学真实水平

### 3. 意图性过冲与回扣 (Planned Overshoot)

- **规划逻辑**：在初始弹道生成时，**主动**注入 15%~45% 的过冲量（距离越远过冲比例通常越高），模拟高水平选手在快速甩枪（Flick）时的“冲击覆盖”本能
- **修正阶段**：弹道末端结合 WorldModel 的实时预测，进行闭环修正
- **观感**：实现比传统 PID 更自然、更具爆发力的 **“一甩即停”** 手感，同时保留明显的人类修正特征

### 5. 截击式预判 (Leading Interception)

- **协同机制**：利用 Fitts 定律计算出的预期移动时长 $MT$，要求 WorldModel 提前预测目标在 $MT$ 时间后的物理位置
- **路径规划**：直接生成指向该“未来截击点”的弹道
- **进化意义**：从传统的“吊尾巴式追踪”升级为 **“直线截击”**，从数学层面极大缩短实际 TTK（Time to Kill），同时保持生物学合理性

### 1.3 SimpleController (调试专用)
* **定位**：**Developer / Debug Mode**。
* **特性**：
    * **直通 (Pass-through)**：`Output = Input`。Strategy 说动多少，它就动多少。
    * **无延迟**：不考虑 `dt`，没有积分累积，没有微分刹车。
    * **用途**：
        1.  **校准 Strategy**：如果 Simple 模式下准星能瞬间准确锁头，说明 Strategy 的 K 值是对的。
        2.  **测试延迟**：用于测量系统从“看到”到“执行”的纯物理链路延迟。
    * **风险**：在 FPS 较低或检测抖动时，鼠标看起来会非常机械和抽搐。

## 二、输入与输出 (I/O)

| 参数 | 类型 | 说明 |
| :--- | :--- | :--- |
| **Input** | `intent_dx/dy` | 来自 `aim_strategies` 的原始几何计数 (Raw Counts)。代表“如果要一步到位，需要动多少”。 |
| **Input** | `dt` | 两帧之间的时间差 (Seconds)。用于积分/微分计算。 |
| **Output** | `float, float` | 最终裁定下发给硬件的移动量 (u_k)。 |

## 三、安全机制

所有控制器（包括 Simple）都必须遵守以下**铁律**：
1.  **Deadzone (死区)**：小于配置阈值（如 0.5px）的微动不执行，防止准星抖动。
2.  **Max Step (硬限幅)**：单帧移动量严禁超过物理上限（如 500 counts），防止因预测异常导致的“大风车”旋转。
